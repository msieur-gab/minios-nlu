MiniOS Agent

Intent: TF-IDF features and logistic regression. Slots: a CRF tagger. Both are trained by the same plain JavaScript that runs them, with no network calls and no dependencies: the button above retrains the whole model on this phone from the bundled training sentences. Weak weights are dropped and the rest stored as 1-byte numbers, which keeps the model small. Dates, times and durations are read by a small rule-based parser, not by the model. Skills are described in plain Markdown files (skills/*.md). Weather and the time in other places come from Open-Meteo, the only network calls; your name and place stay on this phone. Commands are simulated: the trace shows what would run on the Orange Pi, and system values are example figures. Timers and reminders do ring here while the page stays open.
