# Greeting

Hello. Uses your name if the agent knows it.

## Examples
- hi
- hello
- hey
- hey there
- good morning
- good evening
- hello agent
- hi there
- yo
- morning
- hiya
- greetings
- hello computer
- hey buddy
- good afternoon
- howdy

## Replies
- say: Hi. Tell me what to create or open. | Hello. I can create folders and files, or open apps.
- named: Hi {name}. What can I do for you?
